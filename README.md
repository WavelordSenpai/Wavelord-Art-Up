# Wavelord ArtUp

1. Extract the ZIP.
2. Netlify: drag the `Wavelord-ArtUp` folder in, set env var `GROQ_API_KEY`, and trigger Clear cache deploy.
3. GitHub: upload the folder contents, commit, and push to `main`.
4. Test on phone: open the Netlify link or local/APK build, and tap `TAP TO CREATE`.

## APK (GitHub Actions)
Push to `main` (or run `Build ArtUp APK` in Actions). Download `Actions > Artifacts > ArtUp-APK > app-debug.apk`, uninstall any old ArtUp build first, then install. Grant "Display over other apps" once when prompted.
